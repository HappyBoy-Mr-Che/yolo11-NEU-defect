# 缺陷检测数据集标注规范

> 适用对象:参与本项目数据标注/质检的所有人员
> 配套工具: `tools/sam_auto_label.py`(预标注)、`tools/dataset_check.py`(质检)、`tools/dataset_split.py`(划分)、`tools/copy_paste_augment.py`(小缺陷增强)
> 标注格式: **YOLO 目标检测格式**(每图一个同名 `.txt` 标签文件)

---

## 1. 标注格式规范

### 1.1 目录结构

```
dataset/
├── raw/                        # 原始采集图片 (未标注)
├── images/                     # 已标注图片 (jpg/png/bmp)
├── labels/                     # 与 images/ 同名的 .txt 标签 (一一对应)
└── data.yaml                   # 数据集配置 (类别列表 + 路径)
```

**铁律**:每张图片必须有且仅有一个同名标签文件(`a.jpg` ↔ `a.txt`),哪怕图中没有缺陷也要放一个**空文件**。

### 1.2 标签文件内容

每行一个目标,格式为 5 个以空格分隔的数字:

```
<class_id> <x_center> <y_center> <width> <height>
```

- 坐标全部为**归一化值**(除以图片宽高),范围 `[0, 1]`,保留 6 位小数
- 多目标按行排列,行顺序无要求
- 空文件 = 无缺陷负样本(必须保留,用于训练时降低误检)

示例 `IMG_0001.txt`(图中 1 处划痕 + 1 处麻点):

```
5 0.523437 0.671875 0.312500 0.085938
3 0.148438 0.234375 0.046875 0.039062
```

### 1.3 坐标系

以图像**左上角为原点**,x 向右、y 向下。标注工具的坐标输出(像素级)需换算为归一化值:`x_center / 图宽`, `y_center / 图高`, `width / 图宽`, `height / 图高`。本项目脚本 `dataset_check.py` 会自动检测未归一化(>1)的标签并报警。

## 2. 缺陷类别定义

### 2.1 现有类别(钢材表面,NEU-DET 6 类)

| class_id | 名称 | 中文 | 判据 |
|----------|------|------|------|
| 0 | Crazing | 裂纹 | 表面网状/线状开裂,细密、方向不规则,与划痕的区别是**有分叉/网状** |
| 1 | Inclusion | 夹杂物 | 基体中的非金属杂质,多呈点状/团状,边界清晰、颜色与基体差异大 |
| 2 | Patches | 斑块 | 块状缺陷,面积较大(通常 >1% 图像面积),边界不规则,颜色与基体不同 |
| 3 | Pitted_surface | 麻点 | 密集点状凹坑,单点小但成片出现,与夹杂物的区别是**成片、数量多** |
| 4 | Rolled-in_scale | 轧制氧化皮 | 轧制嵌入的氧化皮,呈片状、沿轧制方向拉长,灰黑色,常伴明显边缘 |
| 5 | Scratches | 划痕 | 机械划伤,细长直线/弧线,**无分叉**,与裂纹的区别是方向单一、连续 |

### 2.2 自建数据集扩展类别(车辆零部件)

自建数据集时按同一编号体系追加类别,修改 `cfg/datasets/` 下 yaml 的 `names` 列表与 `nc` 值,同时同步 `utils/config.py` 的 `class_names`。建议新类别遵循以下原则:

- **可区分性**:不同类别之间必须有稳定的视觉差异(形状/纹理/颜色),面试/论文场景需给出类别定义依据
- **可标注性**:单张图中人工标注一个框的平均时间应 < 15 秒,定义过于模糊的类别应合并
- **数量平衡**:每类实例数差异超过 10 倍时,优先考虑扩充数据而非合并类别(可用 `dataset_check.py` 输出每类直方图评估)

## 3. 边界情况标注规则

| 场景 | 规则 |
|------|------|
| **缺陷贴边/出界** | 缺陷被图像边缘截断时,框仍要贴住图像边缘(坐标 = 0 或 1),标注**可见部分**;整块缺陷都在图外则不标 |
| **极小缺陷** | 肉眼可辨认即可标注;边长 < 3 像素的缺陷**不标**(模型学不到,徒增噪声);若小缺陷密集成片,框整个区域为麻点类 |
| **多缺陷重叠** | 不同类别缺陷重叠时**各自独立标注**,允许框重叠;同类缺陷相互重叠时合并为一个框 |
| **同类密集分布** | 同类别缺陷间距小于单个缺陷自身尺寸时,合并为一个框;否则分开标注 |
| **遮挡/反光** | 缺陷被遮挡或反光导致无法辨认类别时**不标**该处,不要猜 |
| **背景纹理误判** | 正常纹理(如加工纹路、油渍、水渍)**不标**;拿不准时先不标并在审核阶段讨论,宁缺毋滥 |
| **一张图多个缺陷** | 全部标出,没有数量上限 |
| **一张图无缺陷** | 保留图片 + 空标签文件(负样本) |

## 4. 标注工具与流程

### 4.1 工具选择

| 工具 | 适用场景 | 备注 |
|------|---------|------|
| [labelImg](https://github.com/HumanSignal/labelImg) | 常规人工标注 | 输出 PascalVOC XML,选 **YOLO 模式**直接出 txt |
| [labelme](https://github.com/labelmeai/labelme) | 多边形精细标注 | 需脚本转矩形框 + YOLO 格式 |
| [AnyLabeling](https://github.com/vietanhdev/anylabeling) | 半自动标注 | 内置 AI 模型辅助,适合大批量 |
| **本项目 sam_auto_label.py** | **推荐首选** | 检测模型出粗框 → SAM 精修掩码 → 自动转 YOLO 标签 + 可视化审核 |

### 4.2 推荐工作流(半自动)

```bash
# 1. 用已训练检测模型 + SAM 对无标注图片预标注
python tools/sam_auto_label.py --source dataset/unlabeled --det-model models/best.pt
# 输出: <out>/labels/*.txt (YOLO 格式) + <out>/vis/*.jpg (掩码可视化)
#        + docs/sam_auto_label_report.md ("无检测"图片清单, 需人工补标)

# 2. 人工审核:逐张对照 vis/ 可视化图检查框贴合度
#    - 框过大/过小: 直接改 <out>/labels/ 对应 txt 的坐标
#    - 漏标: 用 labelImg 打开原图补标
#    - 错标类别: 改 txt 第一个数字 (class_id)

# 3. 审核通过后合并入 dataset/images + dataset/labels
```

### 4.3 纯人工标注流程

1. labelImg 打开 `dataset/raw/`,YOLO 模式逐张画框
2. 类别快捷键按 `data.yaml` 的 `names` 顺序(0~5)
3. 每张图标注后立即保存到 `dataset/labels/`,图片复制到 `dataset/images/`

## 5. 命名与数据管理规范

### 5.1 文件命名

- 图片: `<批次>_<序号>.<ext>`,如 `batch01_0001.jpg`;序号 4 位,禁止中文/空格/特殊字符
- 标签: 与图片**完全同名**的 `.txt`
- 采集批次信息记录在 `dataset/README.md`(相机型号/光照/零部件型号/拍摄日期),便于后续定位问题数据

### 5.2 图片要求

- 原始分辨率不统一时,标注前**不要**预先缩放(标注后再统一用训练侧 resize);必须缩放的,同步等比例缩放图片
- 剔除: 严重失焦、曝光异常、分辨率 < 320×320 的图片
- 同一物理缺陷的连拍图,只保留角度差异明显的帧(去重可用 `dataset_check.py` 的 MD5 检查)

## 6. 质检流程(每批次必做)

### 6.1 自动检查(第一步,标注完成即跑)

```bash
python tools/dataset_check.py --data dataset/data.yaml --splits train val test
```

自动检查项:

1. 图片-标签一一配对(缺标签/缺图片/多余文件)
2. 标签格式合法性(字段数、数值范围、未归一化坐标)
3. bbox 合法性(越界、宽高 ≤ 0、中心点越界)
4. 空标签(负样本)统计
5. 图片可读性(PIL 校验)+ 重复图片(MD5)
6. 每类实例直方图 + bbox 尺寸分布(COCO 标准:小 <32px / 中 <96px / 大)

**任何 ERROR 级别问题必须清零后才能进入训练。**

### 6.2 人工抽检(第二步)

- 每批次随机抽 5% 图片逐张复核框贴合度与类别正确性
- 重点抽检: 预标注通过率低的批次、稀有类实例、小目标(<32px)样本
- 抽检发现问题率 > 10% 时,整批返工

### 6.3 双人复核(自建数据前 3 个批次)

- 标注人自检 → 复核人抽检(10%)→ 争议样本记录到 `dataset/disputes.md`,按第 3 节规则裁决
- 规则更新: 裁决结论补充进本规范第 3 节,保证后续批次一致

---

## 7. 类别均衡与小缺陷增强

`dataset_check.py` 报告中的每类直方图若显示某类实例数不足(如 < 该类目标总数的 10%),用 Copy-Paste 离线增强补充:

```bash
python tools/copy_paste_augment.py --data dataset/data.yaml --multiplier 1 --patches 1 3
```

- 原理: 从源图裁剪缺陷 patch(含边界框)→ 旋转/缩放/亮度抖动 → 粘贴到目标图随机位置(与现有框 IoU ≤ 0.1 才接受)
- 输出可直接合并入训练集,增强样本需在质检流程中走一遍自动检查

## 8. 标注完成后的划分

```bash
python tools/dataset_split.py --src dataset/raw --out dataset/split --ratios 8 1 1
```

- 按"每张图含有的最稀有类别实例数"贪心分层,保证稀有类在 val/test 均有覆盖
- 划分后重新跑 `dataset_check.py` 确认 train/val/test 三个子集均无异常
